# 🛠️ Web 转桌面应用打包工具（跨平台 EXE / Linux / macOS）

这是一个基于 **NeutralinoJS** 的轻量级 HTML/Web 网页一键打包为独立桌面端应用的工具套件。

不仅能将网页打包为 Windows 平台的单文件可执行程序（`.exe`），还**原生支持全平台跨平台打包**，一键同时生成 **Linux** 和 **macOS（苹果系统）** 版本的桌面软件！

打包生成的应用程序体积极其小巧（单文件仅约几兆）、启动飞快、内存消耗极低，且用户端无需预装 Node.js 或任何繁重的环境。

---

## 🌐 跨平台支持矩阵 (Cross-Platform Support)

本项目支持将同一个 Web 网页项目一键编译生成以下全部平台的桌面独立软件：

| 操作系统平台 | 支持架构 | 输出文件类型 | 运行特性 |
| :--- | :--- | :--- | :--- |
| **Windows** | x64（主流 64位 Windows） | `.exe` 单文件 | 即点即用，支持独立图标 |
| **macOS (苹果)** | Apple Silicon（M1/M2/M3/M4 系列）<br>Intel（x64）<br>Universal（通用二进制） | 独立运行程序 | 支持所有主流 Mac 电脑 |
| **Linux** | x64 / ARM64 / ARMhf（树莓派等） | 独立 ELF 二进制 | 兼容 Ubuntu、Debian、CentOS 等 |

> 💡 **多平台打包提示**：  
> 若需要同时打包 Linux 和 Mac 版本，请在运行 `请先点击更新bin运行文件.bat` 时选择 **`[2] 更新全部平台运行文件`**，确保 `bin/` 目录中具备对应平台的核心文件。

## 📂 快速操作流程（新手必读）

请根据你的当前状态，按照以下顺序进行操作：

```
                    ┌─────────────────────────┐
                    │  检查 bin 文件夹状态   │
                    └───────────┬─────────────┘
                                │
          ┌─────────────────────┴─────────────────────┐
          ▼                                           ▼
【初次使用 / bin 为空 / 想升级】             【bin 中已有运行文件】
          │                                           │
  运行: 请先点击更新bin运行文件.bat                     │ (无需更新，直接跳过)
  (可选择仅Windows或全平台内核)                      │
          │                                           │
          └─────────────────────┬─────────────────────┘
                                │
                                ▼
                       双击: 打包向导.bat
                                │
                                ▼
                    放入你的网页 HTML/JS/CSS 文件
                                │
                                ▼
            一键生成 Windows EXE（及 Linux / Mac 产物）！
```

---

### 第一步：检查运行库状态

* **情况 A（已有运行库）：直接跳过更新！**
  * 检查根目录 `bin` 文件夹：如果里面已经有 **`neutralino-win_x64.exe`**，说明当前环境已就绪。
  * 👉 **无需运行更新脚本**，直接进入下一步！

* **情况 B：首次下载、补齐多平台核心或升级内核**
  * 如果 `bin` 目录为空，或者需要补充 **Linux / macOS** 核心，或者希望升级到官方最新版本：
  * 👉 双击运行 **`请先点击更新bin运行文件.bat`**。
  * 脚本自带国内高速镜像防卡死：
    * 按提示选择 `1`：仅更新 Windows 核心（最省空间，仅约 2.4MB）；
    * 按提示选择 `2`：下载全平台 7 个核心（包含 Win + Mac + Linux 全部文件）。

---

### 第二步：运行打包向导

1. 双击运行根目录下的 **`打包向导.bat`**。
2. 输入你的**应用名称**（例如：`图片搜索`、`我的应用` 等）。
3. 脚本会自动为你创建专属工程文件夹，并提示网页资源存放路径。

---

### 第三步：放入网页资源并打包

1. 按照提示，把你做好的 HTML、CSS、JS、图片等前端文件直接复制到该工程的 **`resources`** 文件夹中。
   * 确保主入口页面命名为 **`index.html`**。
   * 如需调用窗口控制（最小化/最大化/关闭）、本地系统读写等桌面原生功能，可在 HTML 中引入 `<script src="js/neutralino.js"></script>`（普通纯网页展示不引入亦可直接打包）。
2. 在命令行中设置窗口标题、窗口宽高（如宽度 900、高度 760）等参数。
3. 选择打包模式：输入 `1`（**Release 模式**，推荐，会自动将全部网页资源内置融合）。
4. 提示打包完成后，前往 **`dist`** 文件夹即可获取打包产物：
   * **Windows 单文件**：位于 `dist/<应用名>.exe`。
   * **全平台构建包**：在 `dist/<应用名>/` 目录下可同时找到对应 Linux 和 macOS 各架构的可执行程序！

## 📁 核心文件与目录说明

| 文件 / 目录名 | 说明 |
| :--- | :--- |
| **`打包向导.bat`** | **主要操作文件**。用于创建项目、配置窗口属性并一键编译封装桌面软件。 |
| **`请先点击更新bin运行文件.bat`** | **辅助更新工具**。用于自动拉取官方最新 Win/Mac/Linux 运行核心与客户端 JS。 |
| **`bin/`** | 存放 Neutralino 底层运行核心（Windows 版 `neutralino-win_x64.exe` 及 Mac/Linux 核心）。 |
| **`resources/`** | **示例与默认模板资源池**（详见下方特别说明）。 |
| **`node_modules/`** | 打包编译工具链依赖（支持全离线打包，请勿随意更改）。 |
| **`dist/`** | **最终交付目录**。生成的单文件应用和跨平台软件包均保存在此。 |

---

### ⚠️ 关于根目录 `resources/` 文件夹的重要说明（必看）

根目录下的 `resources/` 既是一个可供直接运行体验的**示例项目**，也是打包向导的**全局基础模板池**：

1. **`resources/icons/` 目录（切勿删除）**：
   * 存放软件窗口与托盘图标（如 `default.png`）。
   * 💡 **更换默认图标方法**：直接将你自己的 PNG 图标替换到此文件夹中，即可修改生成软件的默认图标！
2. **`resources/js/` 目录（切勿删除）**：
   * 存放核心运行时通信脚本（`neutralino.js` 与 `neutralino.d.ts`）。
   * 每次创建新项目时，打包工具会自动将最新的客户端通信库复制到新工程中，删除会导致应用无法调用桌面原生 API。
3. **`resources/` 根目录下的 `index.html` 与 `css/`**：
   * 官方提供的范例页面，包含完整 UI 样式与基础事件调用，供开发或测试参考。

## ❓ 常见问题 FAQ

### Q1: 打包出来的软件发给其他人使用，需要附带其它依赖文件吗？
> **答：完全不需要！**  
> 打包向导采用单文件封装机制（`--embed-resources`），生成的 Windows 单文件 `dist/xxx.exe` 已经把所有 HTML/CSS/JS 资源与运行引擎内嵌为一体。  
> 交付或分享时，**只需发给对方这一个可执行文件即可**，无须安装任何第三方环境。

### Q2: 可以把打包好的软件发给 Mac 或 Linux 系统的朋友使用吗？
> **答：完全可以！**  
> 本工具基于 NeutralinoJS 全平台内核。只要你的 `bin/` 文件夹内保留了 Mac/Linux 核心（可在运行更新脚本时选择全平台下载），打包时会在 `dist/<项目名>/` 目录下同时生成对应 Mac（Intel / Apple M芯片）和 Linux 的二进制程序，直接发送给对应系统的用户赋予可执行权限即可直接运行。

### Q3: 每次打包新的应用都需要点击更新脚本吗？
> **答：不需要。**  
> 只要 `bin/` 文件夹中的运行程序存在，就可以一直本地离线使用。后续每次打包新应用直接运行 `打包向导.bat` 即可，几秒内即可打包完毕。

### Q4: 运行打包向导提示“缺少 Node.js 环境”怎么办？
> **答：** 打包编译环节需要 Node.js 执行封装脚本。若尚未安装，请前往 [Node.js 官方网站](https://nodejs.org) 下载并安装 LTS 长期支持版本（一路点击“下一步”即可）。
