# 🛠️ Web 转 EXE 桌面应用打包工具

这是一个基于 **NeutralinoJS** 的轻量级 HTML/Web 网页一键打包为 Windows 独立桌面端应用（EXE）的工具套件。

打包出来的 EXE 体积超小（仅需几兆）、内存占用极低，且无需预装繁重的环境。

---

## 📂 快速操作流程（新手必读）

请根据你的当前状态，按照以下顺序进行操作：

```
                    ┌─────────────────────────┐
                    │  检查 bin 文件夹状态   │
                    └───────────┬─────────────┘
                                │
          ┌─────────────────────┴─────────────────────┐
          ▼                                           ▼
【初次使用 / bin 为空 / 想升级】             【bin 中已有运行文件】
          │                                           │
  运行: 请先点击更新bin运行文件.bat                     │ (无需更新，直接跳过)
          │                                           │
          └─────────────────────┬─────────────────────┘
                                │
                                ▼
                       双击: 打包向导.bat
                                │
                                ▼
                    放入你的网页 HTML/JS/CSS 文件
                                │
                                ▼
                   自动生成单文件独立运行 EXE！
```

---

### 第一步：检查运行库状态

* **情况 A（绝大多数情况）：直接跳过更新！**
  * 检查项目根目录的 `bin` 文件夹：如果里面已经有 **`neutralino-win_x64.exe`**，说明运行环境已就绪。
  * 👉 **完全无需运行任何更新脚本**，直接进入下一步！

* **情况 B：需要更新或首次下载运行库**
  * 如果 `bin` 文件夹是空的、丢失了运行文件，或者你希望将内核升级到 NeutralinoJS 的最新官方版本：
  * 👉 双击运行 **`请先点击更新bin运行文件.bat`**。
  * 根据提示按回车，脚本会自动连接并下载最新 Windows 核心文件与客户端 JS 依赖（自带国内镜像防卡死）。

---

### 第二步：运行打包向导

1. 双击运行根目录下的 **`打包向导.bat`**。
2. 输入你的**应用名称**（例如：`图片搜索`、`我的应用` 等）。
3. 脚本会自动为你创建专属工程文件夹，并提示网页资源存放路径。

---

### 第三步：放入网页资源并打包

1. 按照提示，把你做好的 HTML、CSS、JS、图片等前端文件直接复制到该工程的 **`resources`** 文件夹中。
   * 确保入口页面命名为 **`index.html`**。
   * 如果需要调用窗口最大化/最小化/文件系统等原生功能，可以在 HTML 中引入 `<script src="js/neutralino.js"></script>`（普通网页不引入也能正常打包运行）。
2. 在命令行中输入窗口标题、窗口初始宽度（如 900）、高度（如 760）等配置。
3. 选择打包模式：输入 `1`（**Release 模式**，推荐，会自动把所有网页资源与运行内核整合成一个独立的 `.exe`）。
4. 提示打包完成后，直接去 **`dist`** 文件夹即可找到你的可执行文件（例如 `dist/图片搜索.exe`）！

## 📁 核心文件与目录说明

| 文件 / 目录名 | 说明 |
| :--- | :--- |
| **`打包向导.bat`** | **主要操作文件**。用于创建项目、配置窗口属性并将网页打包为 EXE。 |
| **`请先点击更新bin运行文件.bat`** | **辅助更新工具**。仅在 bin 缺失或需要升级官方内核时才需点击。 |
| **`bin/`** | 存放 Neutralino 底层运行时内核（Windows 下需要 `neutralino-win_x64.exe`）。 |
| **`resources/`** | **示例与默认模板资源池**（详见下方特别说明）。 |
| **`node_modules/`** | 打包命令行工具依赖树（离线打包时使用，请勿随意删改）。 |
| **`dist/`** | **最终成果交付目录**。生成的单文件桌面软件放在这里。 |

---

### ⚠️ 关于根目录 `resources/` 文件夹的重要说明（必看）

根目录下的 `resources/` 既是一个可供参考的**示例网页项目**，也是打包向导的**全局默认基础模板**：

1. **`resources/icons/` 目录（切勿删除）**：
   * 存放软件窗口与应用程序的默认图标（如 `default.png`）。
   * 💡 **更换默认图标方法**：直接将你自己的 PNG 图标替换到此文件夹中，即可修改生成软件的默认图标！
2. **`resources/js/` 目录（切勿删除）**：
   * 存放核心运行时通信脚本（`neutralino.js` 与 `neutralino.d.ts`）。
   * 每次通过向导创建新项目时，系统会自动从此目录复制最新的通信库到新工程中，删除会导致打包后的应用无法调用桌面原生接口。
3. **`resources/` 根目录下的 `index.html` 与 `css/`**：
   * 为官方提供的完整范例页面，供开发或测试参考。

## ❓ 常见问题 FAQ

### Q1: 打包出来的软件发给其他人使用，需要带上这个文件夹里的其它文件吗？
> **答：完全不需要！**  
> 打包向导采用单文件打包方案（`--embed-resources`），生成的 `dist/xxx.exe` 已经包含了所有网页资源和运行内核。  
> 交付或分享时，**只需要把 `dist/` 里的 `.exe` 文件发给别人即可**，双击就能直接打开运行。

### Q2: 每次打包新的应用都需要点击更新脚本吗？
> **答：不需要。**  
> `bin/` 里的文件只要存在就是永久可用的，平时打包直接运行 `打包向导.bat` 即可，几秒钟就能生成一个新应用。

### Q3: 运行打包向导提示“缺少 Node.js 环境”怎么办？
> **答：** 打包过程依赖 Node.js 执行编译封装工具。若未安装，请前往 [Node.js 官方网站](https://nodejs.org) 下载并安装 LTS 长期支持版（安装时一路点击“下一步”即可）。
